# extensions/

Scripts, logs and result tables behind the earlier additions (Proposition 5 and its checks, Section 6.8 and Supplementary Sections S-new). The main pipeline in `code/` and `run_all.sh` does not depend on this folder. Each script was run once by the author; the `.log` / `.csv` / `.json` files next to the scripts are the stored outputs. They were not regenerated by `run_all.sh`.

Run from the repository root with `PYTHONPATH=code` (for `ac_baselines` use `PYTHONPATH=code:extensions/ac_baselines`).

| folder | content |
|---|---|
| `transfer/` | numerical checks of the row-stochastic sensitivity matrix, the sup-norm Lipschitz bound and the margin transfer (`check_stochastic.py`, `check_lipschitz.py`, `check_margin_transfer.py`); the unit test is `tests/test_transfer_lemma.py` |
| `tube_theory/` | tube bound through the Kron-form stiffness and incremental energy, counterexamples to the unconditional version, conformal hybrid margin, closed-loop test with tightened limit (`VERDICT.md` is the author's working summary; the tube bound is valid but 14 to 125 times loose, and tightening helps only with several times the base actuator authority) |
| `ac_baselines/` | variant with voltage magnitudes also algebraic, learned algebraic-map baseline (`run_ac_all.sh`) |
| `ac_recal/` | recalibrated physics and library residual in the voltage-magnitude variant, 24 operating points (`PROTOCOL.md`, `README.md`) |
| `contingency_mechanism/` | per-outage decomposition of the twin margin (cushion above the topology shift, test against calibration), `diag_mechanism.py` reproduces the stored margins and coverages of all 35 case39 outages; exploratory, no criterion is claimed |
| `gate_certificate/` | gate false-alarm calibration, fixed-sequence certificate, step-delay runs (`REPORT.md`) |
| `hybrid/` | hybrid of a parametric damping term and the library residual (no gain found) |

Nothing here is a validation on a real system. All cases are the reduced lossless MATPOWER case9 and case39 models of the paper.
