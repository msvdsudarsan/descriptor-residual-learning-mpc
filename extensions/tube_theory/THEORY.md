# THEORY.md  closed-loop / tube constraint-satisfaction attempt (T-A), structural lemmas, counterexamples (T-C)

Scope: reduced model of `code/network_benchmark.py` (classical swing generators, lossless P-theta network, unit voltages).
Everything below is proved from the assumptions stated; numerical checks are in the scripts named in brackets and their `.log` files.
Nothing here is claimed for the full paper pipeline (RK4 discretisation, Newton tolerance, measurement noise are NOT in the theorems; see Section 7).

## 0. Notation
Generators i=1..ng, buses n. delta in R^ng rotor angles, omega speeds, theta in R^n bus angles. C in R^{n x ng}, C[bus(i),i]=1.
Constrained angles ("edges" e): line angles A_e = theta_j - theta_k (weights b_e), and rotor-to-bus angles psi_i = delta_i - theta_bus(i) (weights bg_i).
A_e is a function of (delta, Pd) through the algebraic solution theta(delta,Pd) of g(theta,delta,Pd)=0.
w_e := (weight) * cos A_e (the "Hessian weight" of edge e). kd_i := bg_i cos psi_i, Kd = diag(kd).
J := -d g/d theta = C^T Kd C + sum_lines b_l cos(A_l) (e_j-e_k)(e_j-e_k)^T  (weighted Laplacian + positive diagonal at generator buses; this is `alg_res_jac`'s J).
Electrical power f_i(delta;Pd) = bg_i sin psi_i. span(x) = max_i x_i - min_i x_i. M=diag(M_i), D=diag(D_i).
Level gbar < pi/2, c0 := cos(gbar), tan(gbar) = tangent. "Region R(gbar)": all constrained angles satisfy |A_e| <= gbar.
J1 := J with all cosines replaced by 1, K1 := its Schur complement (below), lambda2 := second smallest eigenvalue of K1.

## 1. Lemma 1 (stochastic sensitivity)   [known from the earlier check; proof written out here]
Assume cos A_e > 0 for all constrained edges, and every connected component of the network contains a bus with a generator.
Then (a) J is symmetric positive definite and a nonsingular M-matrix, (b) S := d theta/d delta = J^{-1} C Kd >= 0 entrywise, (c) S 1 = 1 (row sums exactly 1),
(d) for every x in R^ng and every edge e: |dA_e[x]| <= span(x), where dA_e[x] = z_e x, z_e := dA_e/d delta.
Proof. (a) x^T J x = sum_i kd_i x_bus(i)^2 + sum_l b_l cos A_l (x_j-x_k)^2 >= 0, with equality only if x is constant on each component and zero at a generator bus of the component, i.e. x=0. Off-diagonal entries of J are -b_l cos A_l < 0 on lines, 0 elsewhere (generators only add to the diagonal): J is a Z-matrix, symmetric positive definite, hence a nonsingular M-matrix and J^{-1} >= 0.
(b) Kd>=0, C>=0, J^{-1}>=0. (c) J 1 = C Kd 1 because the Laplacian part annihilates 1; so 1 = J^{-1} C Kd 1 = S 1. (Row sums = 1 uses only invertibility, not cos>0.)
(d) Each (S x)_j is a convex combination of the entries of x, hence lies in [min x, max x]. A line edge has z_e x = (Sx)_j-(Sx)_k, a difference of two such numbers: |.|<= span(x). A generator edge has z_e x = x_i - (Sx)_bus(i): again |.|<=span(x). QED.
Corollary 1 (path version). Let delta(s), s in [0,1], be a C^1 path with velocity v(s), and suppose |A_e(delta(s))| < pi/2 on the path (branch of theta obtained by continuation). Then |d/ds A_e| <= span(v(s)); hence |A_e(delta(1))-A_e(delta(0))| <= int span(v). For the straight segment delta(s)=delta_p+s e: <= span(e).
The best constant: |dA_e[x]| <= G span(x) with G = max_e (1/2)||z_e||_1 <= 1 (z_e has zero sum). [check_counterexamples.py D: G = 0.31 case9, 0.56-0.64 case39.]

## 2. Lemma 2 (structure of the reduced stiffness)
Let W(delta,theta) = sum_i bg_i(1-cos psi_i) + sum_l b_l (1-cos A_l) + Pd.theta. Then dW/dtheta = -g and dW/ddelta = f. Let Wt(delta)=W(delta,theta(delta)).
(a) f = grad Wt, and K := df/ddelta = Kd - Kd C^T J^{-1} C Kd = Kd(I - S_gen) is symmetric, K 1 = 0, 0 <= K <= Kd (Loewner).
(b) x^T K x = min_theta Q(x,theta), Q := sum_i kd_i (x_i-theta_bus(i))^2 + sum_l w_l (theta_j-theta_k)^2.
(c) K = sum_e w_e z_e z_e^T (z_e as in Lemma 1) and dK/dw_e = z_e z_e^T.
(d) If w >= c0 w^(1) edgewise (w^(1) = weights with cos=1) then K >= c0 K1; K1 has null space span(1) when the network is connected, lambda2>0.
(e) (relative variation) along any C^1 curve delta(t) inside R(gbar) with velocity omega: -mu K <= dK/dt <= mu K, mu = max_e |tan A_e| |A_e'| <= tan(gbar) span(omega).
Proof. (a) f_i = dWt/ddelta_i by the envelope theorem (dW/dtheta=0 at theta(delta)); differentiating f through the IFT gives K = Kd - Kd C^T J^{-1} C Kd, obviously symmetric. K1=0: Kd 1 - Kd C^T J^{-1} (C Kd 1) = Kd1 - Kd C^T 1 = 0 (as J1 = C Kd 1). K<=Kd since J^{-1}>=0 makes the subtracted term PSD.
(b) Q is a strictly convex quadratic in theta (Hessian 2J); its minimiser is theta* = J^{-1}C Kd x and the minimum value is x^T(Kd - Kd C^T J^{-1} C Kd)x.
(c) With theta* = S x, each term of Q at the minimiser is w_e (z_e x)^2 (z_e x = A_e[(x,theta*)]); summing gives x^T K x = x^T (sum_e w_e z_e z_e^T) x; K symmetric so K = sum w_e z_e z_e^T. dK/dw_e: by (b) and Danskin's envelope theorem (unique smooth minimiser) d(x^T K x)/dw_e = (z_e x)^2.
(d) Q_w >= c0 Q_{w^(1)} pointwise, so minima compare. x^T K1 x = 0 iff there is theta with x_i = theta_bus(i), theta_j = theta_k on every line, i.e. x constant on each network component.
(e) K depends on t only through the weights w_e(t) = (weight_e) cos A_e(t). By (c), dK/dt = sum_e w_e' z_e z_e^T, with w_e' = -w_e tan(A_e) A_e'. Hence -mu sum_e w_e z_ez_e^T <= dK/dt <= mu sum_e w_e z_e z_e^T, mu = max_e |tan A_e||A_e'|, and |A_e'| = |z_e omega| <= span(omega) by Lemma 1(d). QED  [check_structure.py: symmetric, K<=Kd, representation error 1e-15, K>=c0 K1, J>=c0 J1, |Kdot| <= mu K with observed ratio <= 0.26.]
Consequence for averaged stiffness: for two points delta_p, delta_hat with segment inside R(gbar), Kbar := int_0^1 K(delta_p+s e) ds satisfies f(delta_hat)-f(delta_p) = Kbar e, Kbar symmetric, Kbar >= c0 K1, and (if both trajectories are C^1) dKbar/dt <= mu_bar Kbar with mu_bar = tan(gbar) max(span omega_p, span omega_hat) (average of per-s inequalities, span is convex).

## 3. Lemma 3 (load sensitivity)
Let Pd(t) = Pd0 + dP, and suppose the straight homotopy Pd0 + s dP (rotors fixed) stays in R(gbar). Then
(a) d f/d Pd = Kd C^T J^{-1} =: P >= 0 with 1^T P = 1^T (column sums 1): ||Delta f||_1 <= ||dP||_1.
(b) ||M^{-1/2} Delta f||_2 <= sqrt(max_i bg_i/M_i) * c0^{-1/2} * ||dP||_{J1^{-1}}, where ||y||_{J1^{-1}}^2 = y^T J1^{-1} y.
(c) for every edge e: |A_e(delta;Pd0+dP) - A_e(delta;Pd0)| <= Lam_e ||dP||_{J1^{-1}}, Lam_e := c0^{-1} sqrt(a_e^T J1^{-1} a_e), a_e = e_j-e_k (lines) or e_bus(i) (generator edges).
Proof. IFT: dtheta = J^{-1}(g_delta ddelta - dPd) with g_delta = C^T Kd, so dPe = Kd(ddelta - C^T dtheta) = K ddelta + Kd C^T J^{-1} dPd. (a) nonnegativity from J^{-1}>=0; 1^T Kd C^T J^{-1} = (J^{-1} C Kd 1)^T = 1^T. (b) Delta f = int Kd C^T J^{-1} dP ds; ||M^{-1/2} Kd C^T J^{-1/2}|| <= ||M^{-1/2}Kd^{1/2}|| ||Kd^{1/2}C^T J^{-1/2}|| <= sqrt(max kd/M) * 1, the last because J >= C^T Kd C, and ||J^{-1/2}y||^2 = y^T J^{-1} y <= c0^{-1} y^T J1^{-1} y because J = sum_e w_e cos(A_e)/... >= c0 J1 (Loewner; every edge term is multiplied by cos A_e >= c0). (c) |a_e^T J^{-1} dP| <= ||J^{-1/2}a_e|| ||J^{-1/2}dP|| and the same Loewner bound. QED  [check_structure.py S6; Lam printed in check_tube logs.]

## 4. Theorem 1 (tube theorem, open loop on [0,T])
### Setting
Plant: M omega_p' = Pm + u - D_phys omega_p - f(delta_p;Pd(t)) + M m_s(x_p,u), delta_p' = omega_p (m_s := (plant acceleration - physics acceleration at the same state and load), any bounded function: saliency, friction, ...).
Predictor (continuous-time flow): M omega_hat' = Pm + u - D_phys omega_hat - f(delta_hat;Pd0) + M rhat(x_hat,u), same control u(t), algebraic variables exact.
rhat_i depends on (psi_i, omega_i, u_i) only and is Lipschitz (the clamp in `res_acc` can only reduce the Lipschitz constant).
e := delta_hat-delta_p, eps := omega_hat-omega_p, z := M^{1/2} eps, Kbar as in Section 2, s^2 := e^T Kbar e, V := (1/2)|z|^2 + (1/2) s^2.
### Hypotheses
(H1) Network connected; every component has a generator.
(H2) Regularity level gbar<pi/2: for t in [0,T] the segment between delta_p(t) and delta_hat(t), and the load homotopy Pd0 -> Pd(t) at delta_p(t), lie in R(gbar), and the predicted/plant algebraic solutions are the branch obtained by continuation along them. (Used for Lemmas 1-3.)
(H3) Speed: span(omega_p), span(omega_hat) <= Omega_bar, and |omega_i| <= wbar on [0,T].
(H4) Mismatch: |rhat_i(x_p,u) - m_s,i(x_p,u)| <= rho for all i, t (error of the learned residual along the TRUE trajectory).
(H5) Lipschitz: |d rhat_i/d psi_i| <= a_psi,i, |d rhat_i/d omega_i| <= a_om,i on |psi|<=gbar, |omega|<=wbar, |u_i|<=umax_i, and d := min_i (D_phys,i/M_i - a_om,i) > 0.
(H6) Load: Pd(t)-Pd0 = lambda(t) Pd_nom with |lambda(t)| <= lbar(t), lbar nondecreasing.
(H7) e(0), eps(0) given with V(0)=V0 (V0 = 0 for exact initialisation).
### Constants
theta_bar^2 := max_i M_i a_psi,i^2 /(bg_i c0);  mu := tan(gbar) Omega_bar;  W(t) := rho sqrt(sum M_i) + Wl lbar(t), Wl := sqrt(max_i(bg_i/M_i)/c0) ||Pd_nom||_{J1^{-1}} (or Wl := ||Pd_nom||_1 / sqrt(min M_i), the l1-route from Lemma 3(a); take the smaller);
Lam := max_e Lam_e ||Pd_nom||_{J1^{-1}} (Lemma 3(c)).
### Statement
For all t in [0,T], with y=sqrt(V):
 (E) for every eta>0:  V' <= nu_eta V + (1+1/eta) W(t)^2/(4d),  nu_eta = mu + (1+eta) theta_bar^2/(2d);
 (Y) y' <= (mu/2 + theta_bar^2/(4d)) y + W(t)/sqrt(2).
Consequently V(t) is bounded by the solutions of these scalar inequalities (explicit formulas, `tubelib.tube`; W nondecreasing so it may be frozen at the right end of each step), and
 span(e(t)) <= min{ 2 sqrt(V(t)/(c0 lambda2)),  span(e(0)) + int_0^t 2 sqrt(2V(tau)/min_i M_i) dtau } =: S(t),
 for every constrained angle e:  | A_e(delta_hat,Pd0) - A_e(delta_p,Pd(t)) | <= S(t) + Lam lbar(t).
Constraint satisfaction: if the predicted trajectory satisfies the tightened limits |A_e^pred(t)| <= gamma - S(t) - Lam lbar(t) for all e and t in [0,T], then the plant satisfies |A_e^plant(t)| <= gamma on [0,T], provided H2-H3 hold with gbar >= gamma + Lam lbar(T).
### Proof
Error equation. Subtract plant from predictor and split f(delta_hat;Pd0)-f(delta_p;Pd(t)) = Kbar e - Delta f_l, Delta f_l := f(delta_p;Pd(t)) - f(delta_p;Pd0) (Lemma 2 mean-value, Lemma 3):
 M eps' = -D_phys eps - Kbar e + F + M Dr,  F := Delta f_l + M w_s,  w_s := rhat(x_p)-m_s(x_p),  Dr := rhat(x_hat)-rhat(x_p).
Forcing. ||M^{-1/2}F|| <= ||M^{-1/2}Delta f_l|| + ||M^{1/2}w_s|| <= Wl lbar(t) + rho sqrt(sum M) = W(t) by Lemma 3(b) (the l1 variant: ||M^{-1/2}Delta f||_2 <= ||Delta f||_2/sqrt(min M) <= ||Delta f||_1/sqrt(min M) <= lbar ||Pd_nom||_1/sqrt(min M) by Lemma 3(a)) and (H4).
Residual difference. Along x(s)=x_p+s(x_hat-x_p): d psi_i/ds = ((I-S_gen(s)) e)_i = (Kd(s)^{-1}K(s) e)_i (Lemma 2a), d omega_i/ds = eps_i. By (H5), a.e. in s, |d/ds rhat_i| <= a_psi,i |(Kd^{-1}K e)_i| + a_om,i |eps_i|. Write X := diag(M_i^{1/2} a_psi,i/kd_i(s)). Then ||X K(s) e|| <= ||X K(s)^{1/2}|| sqrt(e^T K(s) e) and ||X K^{1/2}||^2 = ||K^{1/2}X^2K^{1/2}|| <= ||Kd^{1/2}X^2Kd^{1/2}|| = max_i M_i a_psi,i^2/kd_i <= theta_bar^2 (K <= Kd, kd_i>=bg_i c0). Integrating and Cauchy-Schwarz in s: ||M^{1/2}Dr_psi|| <= theta_bar int sqrt(e^TK(s)e) ds <= theta_bar s. And ||M^{1/2}Dr_om|| acts as diag(a_om) z.
Energy. V' = eps^T M eps' + (1/2) e^T Kbar' e + e^T Kbar eps. Insert the error equation: the terms -eps^T Kbar e and +e^T Kbar eps cancel because Kbar is symmetric, leaving
 V' = -eps^T D_phys eps + eps^T F + eps^T M Dr + (1/2) e^T Kbar' e <= -d|z|^2 + |z|(theta_bar s + W) + (mu/2) s^2,
using Lemma 2(e) for the last term, the omega-part of Dr absorbed into d (H5), s^2<=2V. 
(E) By Young, |z|(theta_bar s+W) - d|z|^2 <= (theta_bar s+W)^2/(4d) <= [(1+eta) theta_bar^2 s^2 + (1+1/eta)W^2]/(4d); with s^2 <= 2V and (mu/2)s^2<=mu V this is (E).
(Y) Use all damping on the stiffness-perturbation term: -d|z|^2 + theta_bar|z|s <= theta_bar^2 s^2/(4d) <= theta_bar^2 V/(2d); keep |z|W <= sqrt(2V) W. V' <= (mu+theta_bar^2/(2d))V + sqrt(2) sqrt(V) W; divide by 2 sqrt(V). Both comparison lemmas (Gronwall) give explicit bounds; V0 enters as initial value.
Position bounds. s^2 >= c0 e^T K1 e >= c0 lambda2 |e - mean(e)1|^2 (Lemma 2d); for a zero-mean vector span <= sqrt(2)|.|; with s^2<=2V: span(e) <= 2 sqrt(V/(c0 lambda2)). Velocity route: |eps_i| <= sqrt(2V/M_i), span(e(t)) <= span(e(0)) + int span(eps) <= ... + int 2 max_i|eps_i|.
Angles. A_e(delta_hat,Pd0)-A_e(delta_p,Pd(t)) = [A_e(delta_hat,Pd0)-A_e(delta_p,Pd0)] + [A_e(delta_p,Pd0)-A_e(delta_p,Pd(t))]; first <= span(e) (Corollary 1), second <= Lam lbar (Lemma 3c). Constraint statement: |A^plant| <= |A^pred| + S + Lam lbar <= gamma. QED

### Where each hypothesis is used
H1: Lemma 1 (invertible J, M-matrix). H2: Lemmas 1-3 and the mean-value step (also the branch/uniqueness issue, assumed not proved). H3: mu (Lemma 2e) and the Lipschitz constants a_psi, a_om. H4: forcing W. H5: theta_bar and d (damping must dominate the omega-slope of the learned residual). H6: load terms. H7: initial condition.
### What is NOT claimed
- H2/H3 are hypotheses on the true trajectory. I tried to close them by a continuity (bootstrap) argument, using the bound itself to certify Omega_bar = span(omega_hat)+2 sqrt(2V/Mmin); numerically this fixed-point iteration DIVERGES (bounds ~1e4..1e8) for horizons beyond ~0.3 s on case9, so H3 is NOT self-certifying (logs: "bootstrapped" line in check_tube_*.log). The tests below take Omega_bar as an observed-level hypothesis and verify it a posteriori.
- rho is an assumption, not a theorem about the learned model; calibrating it on separate runs does not guarantee it (stress/case39: test max exceeded the calibration max by 5-12%).
- The condition d>0 is not implied by anything: on case39 and stress-case9 the fitted library has omega-slope up to 3.8-4.0 1/s, larger than the physical damping 3.2 1/s, so (E)/(Y) give NO bound for the learned predictor there.
- No claim about closed-loop (feedback) invariance: u(t) is taken as the same signal in plant and predictor over the window; this is the usual open-loop-in-the-horizon tube statement.
- RK4 discretisation error, Newton tolerance (1e-10), measurement noise are outside the theorem.
- No claim that the bound is tight (it is not, Section 6), no claim that the method (energy function for swing dynamics) is new; the claimed content is the specialisation: sup-norm structure (Lemma 1), Kron-form relative stiffness variation (Lemma 2e), and the explicit constants.

## 5. Corollary: the load term is a structural constant (usable without Theorem 1)
For any predictor that holds Pd frozen at Pd0, the algebraic-angle prediction error at fixed rotor angles satisfies |dA_e| <= Lam_e |lambda| ||Pd_nom||_{J1^{-1}} (Lemma 3c), computable offline from the topology only. case9: Lam = 0.40 rad per unit lambda, i.e. 0.064 rad at lbar=0.16 (2*lamp, lamp=0.08), versus the observed maximum total angle error 0.0164 rad at 0.5 s: the load-only bound is 3.9x the observed total, i.e. NOT vacuous. This is the only part of the tube that is within a small factor of the data. [check_tube_case9.log, column load_ang]

## 6. Numerical verification of Theorem 1 [check_tube.py, logs check_tube_*.log]
Windows: 130 per case (10 held-out static-law runs, 6 s, 1 s horizon, stride 0.4 s), predictor A2 (Newton-projected, learned residual), RK4 with the repo step.
case9 nominal: hypotheses (Omega_bar=1.5 rad/s, gbar=45 deg) hold on all 130 windows; violations of span_obs<=S and of angle error <= S+Lam lbar: 0 of 1300 samples. Tightness (angle bound / max observed angle error): 17.6x at 0.1 s, 71x at 0.5 s, 264x at 1.0 s; rotor-angle span bound / max observed span: 98x, 108x, 422x. Against the paper's conformal envelope at 0.5 s: 1.174 rad vs 0.0116 rad = 101x.
Idealised plant (no saliency/friction, exact damping, predictor = physics, rho=0; only load fluctuation; IDEAL=1): zero violations; bound/observed 15x-51x (case9), 26x-91x (case39), 18x-170x (case9 at load scale 2.75). So even with NO model mismatch the energy bound is >10x loose.
case9 stress (2.75) and case39 nominal with the learned predictor: d<=0, Theorem 1 yields no bound (see "What is NOT claimed").
At 0.5 s the span term alone (1.1 rad = 64 deg) exceeds the whole 30 deg limit, so the tightened feasible set is empty: the bound cannot be used for tightening.

## 7. Counterexamples and scope of Lemma 1 (T-C) [check_counterexamples.py, check_counterexamples.log]
(i) cos<=0 on a line: Lemma 1(a)-(b) can fail while J stays positive definite. Explicit 3-bus example (gens at buses 0,2 with bg=10, lines b=5, line 0-1 at -100 deg, line 1-2 at -15 deg, rotor-bus angles 10 deg): J eigenvalues 2.01, 9.06, 16.5 (positive definite), S has an entry -0.416, row sums still exactly 1 (J1=CKd1 holds regardless), margin gain G = 1.553 > 1; the nonlinear re-solve confirms: rotor span 0.01 -> line-angle change 0.0152-0.0159 rad (ratio 1.52-1.59). Random search (30000 states each): inside the cos>0 region 0 violations (max G = 0.997 / 0.999, both <1); outside, G>1 in 12714/17716 (case9) and 19403/20073 (case39) of the sampled states, G up to 3.2e4 (case9) and 1.7e5 (case39) near singular J.
(ii) component without generator: summing the algebraic equations over the component, line terms cancel pairwise and no generator term exists, so the equations read -sum Pd = 0: inconsistent unless the component load is zero; J has the kernel 1_component. case9 with lines 4-5 and 5-6 removed: lambda_min(J)=7e-15, residual -0.9 pu at the isolated bus. The model is then not index-1; there is no S and no margin transfer.
(iii) islands that each keep a generator: Lemma 1 holds per component (min S entry 0, row sums 1, G=0.275); a common-mode shift of one island's rotors moves that island's bus angles (0.05 rad) but changes no constrained angle (0.0), and a shift of all rotors changes none (4e-17). So span must be taken per component (global span is a valid but conservative bound).
(iv) unmodelled line outage (no islanding): the predictor keeps the pre-outage topology, so with rotor error 0 (span 0) the algebraic angle error is nonzero: max jump 9.2 deg (case9, median 4.1 deg over the 9 single-line outages) and 18.0 deg (case39, median 2.3 deg over 46). No span-based transfer can cover this; the load-term-type bound would need a topology-change term.
(v) Approach to loadability: along the load-scaling continuation the transfer gain stays below 1 (case9 0.31, case39 0.56-0.64) and lambda_min(J) barely moves (case9 2.24 -> 2.09 up to scale 3.4; case39 4.19 -> 3.18 up to 2.7), because the generator edges keep J well conditioned until the rotor-bus angles approach 90 deg. I could NOT exhibit a 1/lambda_min blow-up of the load constant inside the tested range.

So of the ~100x gap to the typical window, ~1.6-5x (load worst case vs typical) is irreducible for a class-wide statement and the rest (about 60x) is the proof's fault: COI energy (7-15x), forcing constants (1.7x), perturbation (1.9x), growth/Young.

## 9. Theorem 3 (COI-reduced energy, Metzler comparison; no sign condition on d)
Extra hypotheses: (H-prop) D_phys = d0 M (all D_i/M_i equal; true in the benchmark); (H5') only |d rhat_i/d psi_i| <= a_psi,i, |d rhat_i/d omega_i| <= a_om,i, no requirement d = d0 - a_om > 0; (H8) a forcing constant phi with ||Pi_perp M^{-1/2} Delta f_l|| <= phi |lambda| (rigorous: phi_rig = sqrt(Wl^2 - (sum Pd)^2/sum M); calibrated: sup over states of ||Pi_perp M^{-1/2} Kd C^T J^{-1} Pd_nom||); delta_om >= max_{i,j}|slope_i - slope_j| (spread of d rhat/d omega across generators; a_om is always admissible).
Notation: q := M^{1/2}1, Pi_perp := I - q q^T/|q|^2, eps_c := 1^T M eps / sum M, eps~ := eps - eps_c 1, e~ := e - (1^T M e/sum M)1, z~ := M^{1/2} eps~, s^2 := e^T Kbar e (= e~^T Kbar e~ since Kbar 1 = 0), Vt := |z~|^2/2 + s^2/2, y := sqrt(Vt), beta := sqrt(sum M) |eps_c|; g_y := (rho sqrt(sum M) + phi lbar)/sqrt2, g_b := lbar sum Pd/sqrt(sum M) + rho sqrt(sum M); Q := [[-d, th/2],[th/2, mu/2]], lmax := lambda_max(Q), d := d0 - a_om, th := theta_bar, mu = tan(gbar) Omega_bar.
Statement. With A := [[lmax, delta_om/sqrt2],[sqrt2 (th + a_om), -d]] (Metzler) the vector x = (y, beta) satisfies x' <= A x + g(t) (componentwise, a.e.), hence x(t) <= the solution of x' = Ax + g (g nondecreasing -> freeze at right endpoints; closed form with expm, `tubelib.tube_coi`). Consequently span(e(t)) <= 2 y(t)/sqrt(c0 lambda2) and every algebraic-angle error <= span + Lam lbar.
Proof. (i) COI: summing the error equation with weights 1 (1^T Kbar = 0, 1^T D = d0 1^T M): sum M eps_c' = -d0 sum M eps_c + 1^T F + 1^T M Dr. 1^T Delta f_l = lambda sum Pd exactly (Lemma 3a), so |1^T F| <= |lambda| sum Pd + rho sum M; |1^T M Dr_psi| <= sqrt(sum M)|M^{1/2}Dr_psi| <= sqrt(sum M) th s; |1^T M Dr_om| <= a_om sum M|eps_i| <= a_om sqrt(sum M)(|z~| + beta). Multiplying by sqrt(sum M): beta' <= -d beta + th s + a_om|z~| + g_b (here -d0 + a_om = -d). (ii) Relative coordinates: M eps~' = -d0 M eps~ - Kbar e + (F + M Dr) - M1 (1^T(F+M Dr)/sum M); in z~: z~' = -d0 z~ - M^{-1/2} Kbar e + Pi_perp M^{-1/2}(F + M Dr). ## 11. Theorem 2 (finite-sample hybrid coverage: conformal span score + deterministic transfer + load term)
Setting. Runs R (initial condition, load parameters, window grid) are drawn i.i.d. (exchangeable suffices) from a fixed distribution; plant, predictor and the (open-loop) input signal in each run are deterministic functions of the run. For a run R, step k in {1..N} define the run-level scores S_k(R) := max over windows w of R of span(e_k(w)) (span of the rotor-angle prediction error after k steps). Given calibration runs R_1..R_n, r := ceil((n+1)(1-alpha)) <= n and q_k := r-th smallest of S_k(R_1..R_n).
(a) (marginal) P( S_k(R_{n+1}) <= q_k ) >= 1 - alpha for each k. (b) (joint) if scales s_k > 0 are fixed independently of R_1..R_{n+1} and q := r-th smallest of max_k S_k(R_i)/s_k, then P( for all k: S_k(R_{n+1}) <= s_k q ) >= 1 - alpha.
(c) (transfer) Assume (R): for each window the segment between plant and predicted rotor angles has all constrained angles with abs < pi/2 (Lemma 1 applies), and (L): the load part of the error satisfies |A_e(delta_p; Pd0) - A_e(delta_p; Pd(t_k))| <= L_k for all e, windows, k, almost surely (e.g. L_k = Lam lbar(t_k), Lemma 3c; or the calibrated version, which is then a hypothesis). Then for every window and every constrained angle e: |A_e^pred - A_e^plant| <= G S_k + L_k with G <= 1 (G = max_e (1/2)||z_e||_1 along the segment; G = 1 is rigorous). Hence P( for every window of R_{n+1}, every k, every e: |A_e^pred - A_e^plant| <= q_k + L_k ) >= 1 - alpha.
(d) (union variant, no deterministic L) if q^L_k is the r'-th smallest, r' = ceil((n+1)(1-alpha/2)), of the run-level load-part scores, and q_k uses alpha/2, then the same statement holds with margin q_k + q^L_k and probability >= 1 - alpha.
Proof. (a) Exchangeability of S(R_1..R_{n+1}) (measurable functions of exchangeable runs): the rank of S(R_{n+1}) among the n+1 values is stochastically at least uniform after random tie-breaking, so P(S_{n+1} <= r-th smallest of the first n) >= r/(n+1) >= 1-alpha (standard split-conformal argument). (b) apply (a) to the scalar score max_k S_k/s_k. (c) Decompose A_e(delta_hat; Pd0) - A_e(delta_p; Pd(t)) = [A_e(delta_hat; Pd0) - A_e(delta_p; Pd0)] + [A_e(delta_p; Pd0) - A_e(delta_p; Pd(t))]; the first bracket is <= G span(e_k) <= S_k by Corollary 1 under (R), the second <= L_k by (L); on the event of (a) S_k <= q_k. (d) union bound over the two events. QED
What is NOT claimed: coverage when the test runs come from another distribution or under a controller that changes the distribution of states (policy-induced shift; the margin is then not exchangeable with its own calibration data); coverage of a single window in a conditional sense; tightness. The advantage over the paper's direct conformal envelope is structural only: ONE scalar span score calibrates all constrained angles (lines and rotor-bus) simultaneously and its deterministic transfer to topology-dependent angles is exact; it is NOT a smaller margin (below).
Empirical verification [conformal_hybrid.py; logs conformal_hybrid_case9_stress.log, conformal_hybrid_case39.log]. n=39 calibration runs, 100 fresh in-family runs, 2 x 40 out-of-family runs (OOD1: load amplitude 0.12-0.18 vs design 0.07-0.11 / 0.08; OOD2: initial rotor offsets x2.5, speeds x2.3). N=5 steps (0.5 s), alpha=0.05.
case9 (load scale 2.75): margins at 0.5 s: direct conformal on total angle 4.1 deg; hybrid H2 (q_span + calibrated Lam*lbar) 8.2 deg; H1 (rigorous Lam) 22.8 deg; H3 (union) 7.8 deg; H4 (conformal on rotor part + calibrated load) 5.9 deg; median observed run-max error 2.9 deg. Coverage in-family: span-only 0.95 (claim >= 0.95), direct 0.95, H1/H2/H3/H4 1.00; OOD1: direct 0.45, H1 1.00, H2 0.90, H3 0.75, H4 0.85, span-only 0.30; OOD2: direct 1.00, hybrids 1.00, span-only 0.975. Lemma-1 transfer check: rotor-part error <= span in all runs/steps (0 violations); deterministic load check: 0 violations in-family, 45 under OOD1 (its amplitude exceeds the design bound, as it should).
case39: margins at 0.5 s: direct 2.0 deg; H2 5.7 deg; H1 13.1 deg; H3 5.0 deg. In-family coverage: span-only 0.93 (finite-sample claim >= 0.95; binomial s.d. with 100 runs is 0.022, so 0.93 is consistent but not a confirmation), direct 0.97, H2 1.00, H1 1.00; OOD1: direct 0.175, H2 0.55, H1 1.00; OOD2: span-only 0.40 (!), direct 0.95, H2/H1 1.00 (the deterministic G=1 + load term absorbs it).
Interpretation. The hybrid is 2.0x (case9) to 2.9x (case39) LARGER than the direct envelope at 0.5 s, because the triangle inequality discards the cancellation between the rotor-response part and the load part (H4 uses the rotor part alone: 5.9 deg; direct total: 4.1 deg). Out-of-family, the deterministic components give some protection, but only H1 (rigorous Lam, margin 22.8 deg on case9, i.e. unusable) is safe under OOD1; no statement beyond the design family is proved.

## 12. What is proved and tight, what is vacuous (summary of Part II)
- Theorem 3 (COI, Metzler): proved; no sign condition on the damping margin; applies to case39 and stress. Zero violations (1200-1300 samples each). Angle bound / max observed error at 0.5 s: case9 learned: 72x with all-rigorous constants -> 20x with calibrated phi and Lam -> 14x with also a calibrated Lipschitz box; case9 stress, all calibrated, 21x (rigorous 102x); case39, all calibrated, 38x (rigorous 125x); idealised physics predictor: case9 4.8x (calibrated; rigorous 43x), case39 15x (calibrated; rigorous 86x). [check_tube2_*.log]
- Theorem 4 (cross term): proved; feasible only for the physics-type predictor; its gain over Thm 3 is small (case9 ideal, 1.0 s: 7.9x vs 10.2x; at 0.5 s both ~4.7x).
- Theorem 2 (conformal hybrid): proved finite-sample statement; empirically verified in-family; not tighter than the direct envelope (2.0-2.9x larger).
- Unconditional (rigorous-constants) deterministic bounds remain 43-125x above the observed maximum at 0.5 s: three ingredients cannot be removed within the adversarial class: (1) the load class itself (worst-case amplitude/frequency/phase vs typical: 1.6-5x); (2) uniform (state-independent) constants for the load force and for the Lipschitz box (Cauchy-Schwarz/Loewner steps, 1.7-4x); (3) the stiffness perturbation of the learned residual (19 % relative change vs zeta ~ 0.06), which makes the energy argument lose exponentially fast; a bound that treats it as an unknown force cannot exclude resonant amplification, and for a lightly damped oscillator that is correct behaviour of the worst case, not slack of the proof.
