# Archive record

Release 2.0.0 (October 2026) accompanies the manuscript prepared for *Electric Power Systems Research*. To archive it: create a GitHub release `v2.0.0` of https://github.com/msvdsudarsan/descriptor-residual-learning-mpc (the Zenodo integration reads `.zenodo.json`), copy the new version DOI, and add it to `README.md`, `CITATION.cff` and to the manuscript data statement and reference list. No DOI is written anywhere before Zenodo has assigned it.

The manuscript source and PDF are intentionally not part of this repository.
